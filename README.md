# Dennis's Blog

网址：https://dennis-lee1214.github.io/blog/

用 [Quartz](https://quartz.jzhao.xyz/) 生成，推送到 `main` 后由 GitHub Actions 自动发布。

## 写文章

1. 用 Obsidian 打开 `content` 文件夹（作为一个库）
2. 在 `posts` 文件夹里新建笔记，可以用 `templates/博客模板` 插入开头信息
3. 写完把 `draft: true` 删掉（或改成 `false`），否则不会发布
4. 用 GitHub Desktop 提交并 Push，一两分钟后网站更新

图片放在 `attachments` 文件夹。
